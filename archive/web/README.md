# SubTrans — সাবটাইটেল ট্রান্সলেটর

যেকোনো ভাষার সাবটাইটেল ফাইল AI দিয়ে নিজের ভাষায় অনুবাদ করার একটা ওয়েব অ্যাপ। পুরোটা
ব্রাউজারেই চলে — কোনো সার্ভার নেই, তাই GitHub Pages-এ বিনা খরচে হোস্ট করা যায় এবং API key
কোথাও যায় না।

এক বসায় পুরো সিজনের ফাইল ছেড়ে দিলে সবগুলো অনুবাদ হয়ে একটা ZIP হয়ে ফেরত আসে, টাইমিং
অক্ষত থাকে, আর চরিত্রের নাম সব এপিসোডে একই বানানে থাকে।

## কেন আলাদা

চ্যাটে সাবটাইটেল পেস্ট করে অনুবাদ করালে তিনটা জিনিস নষ্ট হয়। এই অ্যাপ তিনটাই কোড দিয়ে
বন্ধ করে:

**টাইমিং স্লিপ।** টাইমস্ট্যাম্প কখনো মডেলের কাছে যায় না। প্রতিটা লাইন একটা id নিয়ে যায়,
সেই id ধরে ফেরত বসে। কোনো ব্যাচ যদি একটা লাইনও কম ফেরত দেয়, ব্যাচটা অর্ধেক করে আবার
পাঠানো হয় — ফাঁকটা কখনো মেনে নেওয়া হয় না।

**নামের অসঙ্গতি।** প্রতি সিরিজের একটা গ্লসারি থাকে, যেটা প্রতিটা রিকোয়েস্টের সাথে যায়।
একবার ঠিক করে দিলে ২৯০ এপিসোড জুড়ে সেটাই চলে।

**ধীরগতি।** ব্যাচগুলো সমান্তরালে চলে, rate limit-এ আটকালে নিজে থেকে অপেক্ষা করে আবার
চেষ্টা করে।

এছাড়া ইটালিক ট্যাগ, ASS override block (`{\an8}` ইত্যাদি) আর লাইন ব্রেক অনুবাদের আগে সরিয়ে
রেখে পরে হুবহু বসিয়ে দেওয়া হয়, যাতে স্টাইল নষ্ট না হয়।

## সাপোর্টেড ফরম্যাট

`.srt` · `.vtt` · `.ass` / `.ssa`

ASS ফাইলের ক্ষেত্রে শুধু Dialogue লাইনের টেক্সট বদলায় — স্টাইল, ফন্ট, পজিশন, Comment লাইন
সব অপরিবর্তিত থাকে।

## চালাতে হলে

```bash
npm install
npm run dev
```

তারপর সেটিংসে গিয়ে একটা Gemini API key বসাতে হবে। ফ্রি key পাওয়া যায়
[Google AI Studio](https://aistudio.google.com/apikey)-তে। key শুধু এই ব্রাউজারের
localStorage-এ থাকে এবং সরাসরি Google-এর API-তে যায়।

```bash
npm test     # পার্সারের টেস্ট — টাইমিং ঠিক থাকছে কিনা
npm run build
```

## GitHub Pages-এ হোস্ট করা

রিপোটা GitHub-এ পুশ করার পর Settings → Pages → Source-এ **GitHub Actions** বেছে নাও।
`main`-এ পুশ করলেই `.github/workflows/deploy.yml` নিজে থেকে বিল্ড করে পাবলিশ করবে।
সাইটটা পাওয়া যাবে `https://<username>.github.io/<repo>/` ঠিকানায়।

## এখন যা আছে

- ফাইল ড্রপ করে একসাথে অনেক ফাইল অনুবাদ
- সিরিজভিত্তিক গ্লসারি — নিজে থেকে তৈরি হয়, হাতে এডিট করা যায়
- আলাদা ফাইল বা পুরোটা ZIP করে ডাউনলোড
- ভাষার ধরন, ব্যাচ সাইজ, সমান্তরাল সংখ্যা — সব সেটিংসে নিয়ন্ত্রণযোগ্য

## পরের ধাপ

- OpenSubtitles থেকে সিরিজের নাম লিখে সরাসরি সাবটাইটেল খোঁজা ও নামানো
- ট্যাব বন্ধ হলেও কাজ যেখানে ছিল সেখান থেকে চালু হওয়া (IndexedDB)
- অনুবাদের পাশাপাশি মূল লাইন দেখে হাতে ঠিক করার এডিটর
