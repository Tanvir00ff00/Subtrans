# SubTrans

সাবটাইটেল ফাইল নিজের ভাষায় অনুবাদ করার অ্যান্ড্রয়েড অ্যাপ। অনুবাদ হয় ফোনেই, অফলাইনে,
কোনো দৈনিক সীমা ছাড়া — AI ডাকা হয় শুধু সেই অল্প কিছু লাইনের জন্য যেগুলো ইঞ্জিন ঠিকমতো
পারেনি।

## কেন এভাবে

একটা এপিসোডে প্রায় ৩০০ লাইন সংলাপ থাকে। ২৯০ এপিসোডের একটা সিরিজ মানে ৯০ হাজার লাইন।
প্রতিটা লাইনের জন্য AI ডাকলে কোনো ফ্রি কোটাই টিকবে না, আর সময় লাগবে ঘণ্টার পর ঘণ্টা।

তাই কাজটা ভাগ করা হয়েছে। **ML Kit-এর অন-ডিভাইস মডেল** সব লাইন অনুবাদ করে — একবার ভাষার
মডেল নামালে (৩০-৪০ MB) তারপর ইন্টারনেট ছাড়াই, বিনামূল্যে, আনলিমিটেড। **AI ডাকা হয় প্রতি
সিরিজে বিশ-ত্রিশবার**, প্রতি লাইনে নয়: একবার গ্লসারি বানাতে, আর যে লাইনগুলো নিয়ে ইঞ্জিন
সন্দিহান সেগুলো ঠিক করতে।

## তিনটে সুরক্ষা

মেশিন ট্রান্সলেশনের তিনটে চেনা দুর্বলতা কোড দিয়ে বন্ধ করা আছে।

**টাইমিং স্লিপ।** টাইমস্ট্যাম্প কখনো অনুবাদকের কাছে যায় না। প্রতিটা লাইন নিজের জায়গায়
ফিরে বসে, তাই অনুবাদ যেমনই হোক, সময় কখনো এলোমেলো হয় না।

**নাম বিকৃতি।** চরিত্রের নাম আর বিশেষ শব্দ অনুবাদের *আগেই* প্লেসহোল্ডার দিয়ে ঢেকে দেওয়া
হয়, পরে গ্লসারি থেকে ঠিক বানানটা বসানো হয়। এক সিরিজের সব এপিসোডে নাম একরকম থাকে।

**নীরব ব্যর্থতা।** প্রতিটা লাইন অনুবাদের পর যাচাই হয় — ট্যাগ হারিয়েছে কিনা, ইংরেজি রয়ে
গেছে কিনা, লাইন অস্বাভাবিক লম্বা বা শব্দ পুনরাবৃত্ত কিনা। সন্দেহজনকগুলো চিহ্নিত হয়ে
থাকে, সেগুলোই AI-তে যায় বা তুমি হাতে ঠিক করো।

## ফিচার

ফাইল খুলে ভেতরটা পড়া যায় — মূল আর অনুবাদ পাশাপাশি, খোঁজা যায়, যেকোনো লাইন হাতে ঠিক
করা যায়। টাইমিং ±সেকেন্ডে সরানো যায় (ভিন্ন রিলিজের জন্য কাটা সাবটাইটেল উদ্ধারের জন্য),
খালি ও পুনরাবৃত্ত লাইন বাদ দেওয়া যায়, আর ফাইলের আসল ভাষা শনাক্ত করা যায়।

গ্লসারি সিরিজ অনুযায়ী সেভ থাকে। আলাদা "নিয়ম" ট্যাবে খুঁজে-বদলে দেওয়ার নিয়ম লেখা যায়,
যা অনুবাদের পর প্রতিটা লাইনে চলে। দ্বিভাষিক ফাইল বানানো যায় — প্রতিটা অনুবাদের নিচে মূল
লাইন, ভাষা শেখার সময় কাজে দেয়। মডেল ম্যানেজার থেকে অপ্রয়োজনীয় ভাষার মডেল মুছে জায়গা
খালি করা যায়।

সাপোর্টেড ফরম্যাট: `.srt` · `.vtt` · `.ass` / `.ssa`। ASS ফাইলে শুধু সংলাপের টেক্সট বদলায়
— স্টাইল, ফন্ট, পজিশন সব অপরিবর্তিত থাকে।

## বানাতে হলে

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

ডিভাইসে টেস্ট চালাতে (ফোন USB দিয়ে যুক্ত থাকতে হবে):

```bash
./gradlew :app:connectedDebugAndroidTest
```

ডিভাইস-টেস্টগুলো আলাদা করে দরকার, কারণ অ্যান্ড্রয়েড ICU দিয়ে রেগেক্স কম্পাইল করে আর
ডেস্কটপের JVM অন্য ইঞ্জিন ব্যবহার করে — ল্যাপটপে পাস করা রেগেক্স ফোনে ক্র্যাশ করতে পারে।
`RegexCompilesOnDeviceTest` ঠিক সেটাই পাহারা দেয়।

## রিলিজ

`v` দিয়ে শুরু হওয়া ট্যাগ পুশ করলে GitHub Actions নিজে থেকে APK বানিয়ে Releases পেজে তুলে
দেয়।

```bash
git tag v0.1.0 && git push origin v0.1.0
```

সাইনিং কী রিপোজিটরিতে রাখা হয় না। লোকালি `keystore.properties` (গিটইগনোর করা), আর CI-তে
রিপোজিটরি সিক্রেট থেকে আসে — `keystore.properties.example` দেখো। কী না থাকলেও বিল্ড হয়,
শুধু APK অস্বাক্ষরিত থাকে।

> সাইনিং কী হারালে ফোনে ইনস্টল করা অ্যাপটা আর কোনোদিন আপডেট করা যাবে না — অ্যান্ড্রয়েড
> ভিন্ন স্বাক্ষরের আপডেট নেয় না। `release.jks` ব্যাকআপ রাখো।

## AI key

AI পলিশ ঐচ্ছিক — বন্ধ রাখলে অ্যাপ পুরোপুরি অফলাইনে চলে। চালু করতে সেটিংসে একটা Gemini
API key লাগে ([Google AI Studio](https://aistudio.google.com/apikey) থেকে ফ্রি নেওয়া যায়)।
key শুধু ফোনেই থাকে, সরাসরি Google-এ যায়, মাঝখানে কোনো সার্ভার নেই।
